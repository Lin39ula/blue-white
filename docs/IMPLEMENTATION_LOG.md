## 已知限制
- 第五幕缺少正式传承资料：保持编辑式叙事与资料席位，没有虚构历史、匠人或图片。
- 材料真实照片缺失。
- 核心 GLB 没有身份元数据；默认莲纹玉壶春瓶照片按器形、纹饰视觉对应，来源沿用用户资料。
- Match Cut 是近似轮廓匹配，非经过摄影标定的像素级匹配。
- DIY 修型轮廓仍为程序化教学轮廓；并非原 GLB 精密复刻。
- 烧制为灯光、窑口与火焰的视觉模拟，练泥为受控形变，没有物理模拟。
- 原模型约 150 万三角形，未改动或简化原件；软件 WebGL 截图会报告 ReadPixels 性能警告，实机移动 GPU 帧率未测。
