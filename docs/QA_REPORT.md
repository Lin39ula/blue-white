## 仍然存在的限制

1. 缺少传承资料 ZIP 与材料真实照片。第五幕不能填入真实人物、历史图片或年代时间线。
2. GLB 未提供身份与摄影标定元数据；照片依据器形纹饰视觉对应，Match Cut 不是像素级标定。
3. 原模型 79 MB、约 150 万三角形；未修改原件。真实移动 GPU 帧率和 Safari/iOS 尚未测量。
4. DIY 为程序化教学模型与视觉模拟，不是文物精密复制或真实烧成物理模拟。
