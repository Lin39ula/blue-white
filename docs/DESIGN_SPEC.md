# 视觉设计系统

采用深墨色 #0d1923、瓷白 #e7e3d8、钴蓝与低饱和蓝灰色。中文主标题使用本机宋体类衬线字体，导航与操作说明使用清晰的无衬线字体，不依赖外部字体服务。

统一固定导航、章节编号、页脚与细线语言；第一与第三幕为留白中的器物展示，第二幕为左侧空间爆炸图与右侧材料展签，第四幕为真实照片和资料展签，第五幕为纵向编辑时间线。

DIY 使用独立程序化模型。桌面端分为轮廓/参数区、模型区、视频区；移动端依次展示工序、模型、编辑区和视频。主线默认滚轮浏览章节，点击观察模式后开启模型缩放，避免控制争用。

三个关键转场使用统一章节状态：纹样特写与材料展开，材料聚合与原模型重现，正面模型与莲纹玉壶春瓶照片的尺寸位置匹配。最后一项是近似轮廓匹配；原模型与照片之间没有原始摄影标定数据。

真实材料照片和传承人物、历史资料缺失，因此保留资料席位；不生成假文物或假人物作为内容。
