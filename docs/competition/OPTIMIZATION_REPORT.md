## 浏览器检查结果

- 主验收：`qa/competition-verified/report.json`，57 项检查全部通过；57 项包含最终汇总断言。
- 专项恢复与实际编辑：`qa/competition-recovery/report.json`，9 项检查全部通过。
- 正常流程：未捕获到页面未处理异常，HTTP 400 及以上资源响应为 0。该计数不是对所有浏览器驱动警告的统计。
- 故障注入：模型中断后重试成功；图片中断后恢复；视频中断后恢复；藏品资料 503 后恢复；WebGL 不可用时仍能浏览藏品。
- 慢网：使用 200 ms 延迟、128 KiB/s 下载限速，确认模型下载反馈和等待期间的藏品浏览。没有在该速度下等待完整 75 MiB 模型下载完毕。
- 操作：材料三选、六道工序与六段视频、实际瓶身绘画、轮廓方向键编辑、施釉、烧制完成、原始器物恢复、三维旋转/缩放、八件藏品、左右键、传承/创新均有实际操作记录。
- 窗口规格：同一会话依次调整四种宽度并浏览五幕及结语，未发现横向溢出。手机工作台滚动后的视频点击命中测试通过。

## 转场与视觉证据

主截图目录 `qa/competition-verified/` 保存 **61 张截图**，包括四种尺寸的五幕与结语、三个材料状态、DIY、烧制成品、八件藏品、移动工作台、慢网、WebGL 降级及六段转场关键帧。

六段完整行程为第一幕→第二幕、第二幕→第三幕、第三幕→第四幕、第四幕→第五幕、第五幕→结语、结语→首页。`transition-before-end-*.png` 与 `transition-end-*.png` 为结束前后关键帧。

`transition-audit.json` 记录开始、结束前、结束及稳定状态的相机与模型数据。六段结束点均通过连续性阈值：位置变化 <0.03 场景单位，相机变化 <0.02，缩放变化 <0.05，透明度变化 <0.02。实际六段的最大位置差约 0.000136、最大缩放差约 0.000721、最大透明度差约 0.003393。

连续性统计针对完整行程的结束点。返回首页时滚动经过的中间章节被标为中断；后续专门的快速导航和窗口尺寸调整不混入完整行程结束点统计。快速导航能最终稳定归位另有浏览器断言。

已查看多轮实际截图并修正移动材料区重叠、多余“0”、画布拦截底部导航和异步工作台焦点问题。较早的 `competition-final`、`competition-release` 报告保留了发现问题的失败记录，以本目录 `competition-verified` 和 `competition-recovery` 的复验结果为准。

## 复现命令

```powershell
npm ci
npm run build
npx playwright install chromium
# 可选：设置 CHROME_129 为独立 Chrome 129 可执行文件的绝对路径
$env:MOTION_QA='1'
$env:QA_DIR='qa/competition-verified'
node scripts/competition-qa.mjs
node scripts/transition-audit.mjs qa/competition-verified
node scripts/competition-recovery.mjs
node scripts/submission-audit.mjs
```

主验收自行启动 5187 端口生产预览，专项测试使用 5188。没有设置 CHROME_129 时主验收使用 Playwright Chromium，不能因此称为 Chrome 129 验收。截图使用软件 WebGL，不能据此宣称所有设备都达到稳定帧率。
